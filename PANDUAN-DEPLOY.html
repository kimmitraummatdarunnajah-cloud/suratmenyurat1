🗺️ Langkah-Langkah

Deploy dalam 3 Langkah Mudah

Tidak perlu keahlian teknis — cukup ikuti panduan berikut

1
Buat Akun & Repository GitHub 5 menit

Jika belum punya akun GitHub, daftar terlebih dahulu di github.com. Setelah masuk, buat repository baru untuk menyimpan file aplikasi.

🖱️ Cara Membuat Repository
1️⃣
Buka github.com dan login ke akun Anda
2️⃣
Klik tombol "New" (hijau) di pojok kiri atas, atau buka github.com/new
3️⃣
Isi Repository name dengan: surat-pkp
4️⃣
Pilih Public — ini wajib agar GitHub Pages dapat aktif secara gratis
5️⃣
Klik tombol "Create repository" (warna hijau di bawah halaman)
2
Upload File ke Repository 3 menit

Upload semua file dari folder paket ke repository GitHub yang baru dibuat. Pilih cara yang paling mudah untuk Anda.

⭐ Cara A — Upload Langsung (Direkomendasikan, tanpa Git)
1️⃣
Di halaman repository kosong, klik link "uploading an existing file"
2️⃣
Seret dan lepas semua file berikut ke area upload: index.html README.md .nojekyll _config.yml
3️⃣
Tunggu proses upload selesai (lihat progres di bawah setiap file)
4️⃣
Di bagian "Commit changes", tulis pesan: Upload aplikasi SiSuRAT PKP
5️⃣
Klik tombol "Commit changes" warna hijau
💡
Catatan file .nojekyll: File ini tidak memiliki konten (kosong), fungsinya hanya sebagai penanda. Pastikan file ini ikut terupload. Jika tidak terlihat di file manager karena diawali titik, aktifkan tampilan "Show hidden files".
💻 Cara B — Via Git (untuk yang sudah familiar)
Terminal / Command Prompt
# 1. Clone repository kosong yang sudah dibuat
git clone https://github.com/USERNAME/surat-pkp.git
cd surat-pkp

# 2. Salin semua file dari folder paket ke sini
#    (index.html, README.md, .nojekyll, _config.yml)

# 3. Tambahkan semua file
git add .

# 4. Commit
git commit -m "Upload aplikasi SiSuRAT PKP"

# 5. Push ke GitHub
git push origin main
ℹ️
Ganti USERNAME dengan username GitHub Anda yang sebenarnya.
3
Aktifkan GitHub Pages 2 menit

Setelah file terupload, aktifkan fitur GitHub Pages agar aplikasi dapat diakses melalui internet.

⚙️ Pengaturan GitHub Pages
1️⃣
Di halaman repository, klik tab "Settings" (pojok kanan, ikon roda gigi)
2️⃣
Di menu kiri, scroll ke bawah dan klik "Pages" (di bawah section "Code and automation")
3️⃣
Di bagian "Source" — pilih "Deploy from a branch"
4️⃣
Pada dropdown Branch: pilih main dan folder / (root)
5️⃣
Klik tombol "Save"
⏱️
Tunggu 1–3 menit. Refresh halaman Settings → Pages. Akan muncul kotak hijau berisi URL aplikasi Anda.

🌐 URL Aplikasi Anda

🔗
https://USERNAME.github.io/surat-pkp
✅
Berhasil! Jika muncul notifikasi berwarna hijau di halaman Settings → Pages, berarti aplikasi Anda sudah online. Bagikan URL tersebut kepada rekan-rekan di bidang PKP.
🔧 Troubleshooting

Solusi Masalah Umum

Jika ada kendala, cek solusi berikut

⚠️
Halaman menampilkan 404 (Not Found)
Pastikan file bernama persis index.html (bukan Index.html atau nama lain). GitHub Pages mencari file index.html sebagai halaman utama. Tunggu juga 3–5 menit setelah mengaktifkan Pages.
⚠️
Opsi "Public" tidak tersedia saat buat repository
GitHub Pages gratis hanya untuk repository Public. Jika menggunakan akun organisasi/edu, mungkin perlu upgrade. Solusi: pastikan pilih Public saat membuat repository.
⚠️
File .nojekyll tidak bisa diupload (tidak terlihat)
File diawali titik tersembunyi di Windows. Buka File Explorer → View → centang "Hidden items". Di Mac: tekan Cmd + Shift + . untuk tampilkan file tersembunyi.
💡
Data tidak tersimpan antar perangkat? Ini normal — aplikasi menggunakan localStorage browser. Untuk backup rutin, gunakan tombol Export CSV di halaman Surat Masuk dan Surat Keluar.
